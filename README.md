## v3.2 수정 (11/08, 입력창·'내가 할 일' 피드백 반영)

## v3에서 바뀐 것 (11/07)

- 환자 모드 기본 화면 = **근거 지도**: 시험을 탭으로 하나씩 고르고, `내 기록 → 시험 조건 → 결론` 세 칸을 선으로 잇습니다.
  - 내 기록: 이 시험 판정에 쓰인 원문 문서(종류·날짜), 누르면 원문과 하이라이트
  - 시험 조건: 최신 라운드 판정으로 묶음. 결과를 정한 조건(`trial_decision.why`), 맞지 않는 조건, 아직 확인이 필요한 조건은 펼쳐 두고, 기록에 없어 확인하지 못한 제외 조건, 맞는 조건, 행정 조건은 접어 둠 (조건 맞음 시험은 맞는 조건을 펼침)
  - 결론: 시험 판정, 에이전트 6 첫 문장, 상태별 개수, 국내 모집 기관 수, 모집 상태 확인 시점
  - 선: 문서 → 조건은 근거 엣지 종류(뒷받침 실선, 근거 부족 점선, 기간 지남 주황), 묶음 → 결론은 묶음 상태 색. 마우스를 올리거나 포커스하면 그 경로만 진하게
  - 조건 글은 `data/ko.json` 기계 번역(팀 결정: 번역 사용), 번역이 없으면 원문. 누르면 근거 패널에서 원문 기준과 근거가 열림
  - 좁은 화면(본문 760px 이하)은 결론 → 조건 → 기록 순으로 쌓고, 선 대신 조건 안에 문서 칩을 보임
- 답 후 상태: 바뀐 조건에 테두리, `이전 상태 → 지금 상태`, `답으로 바뀜` / `재판정 중 바뀜` 구분 (요청 문서의 에이전트 3 참고 항목), 카드 없이 남은 조건 표시

### 내용 정리 (11/05)

- 답 전후 카드 비교를 `card_id` 대신 (카드 종류, 기준 ID)로 바꿈. 에이전트 5가 다시 돌 때마다 번호가 바뀌어 v1은 '사라진 카드 9개'로 셌지만, 실제는 해결 2, 번호만 바뀜 5, 카드 없이 남은 기준 3개(NCT02714634-E01, E09, NCT05428488-E07)
- 환자용: 모든 기준이 행정 기준인 카드(동의서, 보험, 수감 여부 등)는 '연구기관이 확인하는 행정 조건 N개' 한 줄로 묶음. 의료진용에는 그대로 표시
- 환자용: '해당되지 않는 시험' 접기와 '기준별로 보기' 버튼 제거 (에이전트 6 문장이 없고, 영어 기준 표로 넘어가던 부분)
- 의료진용 '판정 이유'를 코드 대신 상태 칩 + 기준 ID 링크로 표시

내용 문장(에이전트 6 `sentences[].text`)과 데이터 파일은 v1과 같습니다. 고친 고정 문구는 두 줄입니다.

- 상단 배너: "합성 데이터 · 연구용 데모 — 미리 실행한…" → "합성 데이터로 만든 연구용 데모입니다. 미리 실행한 파이프라인 결과를 재생합니다."
- 면책 자리 표시: "[면책 고지 문구 — 팀 확정 후 그대로 삽입]" → "[면책 고지 문구: 팀 확정 후 그대로 삽입]"

새로 넣은 파일: `fonts/pretendard/` (Pretendard Variable 동적 서브셋, SIL OFL 1.1), `data/ko.json` (기준·시험 제목 번역, 157개). 없으면 영어 원문으로 보입니다. 화면에 번역을 쓸지는 팀 결정 대기(요청 8)입니다.
